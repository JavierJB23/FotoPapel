REVELO v1.10.0 — BLOCK 02 · FIX06 — Separación del editor libre y los fondos

BASE: v1.10.0 BLOCK02 FIX05; compilación de GitHub #106 completada correctamente.

QUÉ CAMBIA
- «Diseño libre» se dedica exclusivamente a la composición de fotos:
  mover, redimensionar, girar, superponer y navegar por hojas.
- Se retira «Fondo de la hoja» y «Elegir color…» de esa ventana.
- Sólo «Fondos por foto · opacidad» modifica fondos comunes, individuales,
  imágenes y opacidad. Esos fondos permanecen visibles en Diseño libre.
- Abrir, navegar, guardar o cancelar una composición nunca altera fondos.
- El render de Diseño libre hereda exactamente el fondo de la exportación.
- Se conservan el QR bidireccional y las funciones anteriores.

PARA SUBIR A GITHUB
1. Descomprime el ZIP.
2. Ve a github.com/JavierJB23/FotoPapel -> Add file -> Upload files.
3. Arrastra ui_fix_v183.py, revelo_background_editor_separation.py y
   la carpeta tests (con test_v110_fix06_separacion_editor_fondos.py).
4. Commit changes. Sin editar archivos manualmente.
