PARA SUBIR A GITHUB (sin editar código):
1. Descomprime el ZIP en una carpeta.
2. Abre tu repositorio de Revelo en GitHub.
3. En Add file > Upload files, arrastra los dos archivos .py de la raíz
   y la carpeta tests. Confirma los cambios (Commit changes).
4. GitHub ejecutará automáticamente sus pruebas y la compilación.
5. Descarga Revelo-Windows-CARPETA si la ejecución está en verde.
